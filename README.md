## Что это

FZ Manager — это не «ещё один проводник». Это мощная файловая среда телефона:
умная навигация, безопасный Root, полноценный ИИ-агент с инструментами и
помощник Физзи, который знает о приложении всё.

## Возможности

### 📁 Файлы
- **Умный поиск путей** — на каждую букву подсказывает реально существующие
  папки и исправляет опечатки: `/data/lokal` → `/data/local`.
- Список и сетка, сортировка (имя/дата/размер), мгновенный поиск внутри папки.
- Выделение долгим тапом, массовые действия: избранное, безопасное удаление.
- Просмотр изображений с зумом и текстовых файлов (до 512 КБ).
- Избранное, закладки путей, недавние — всё сохраняется между запусками.

### 🐉 Root и Ядро
- **Раздел Root** — навигатор по системным файлам через `su` (только чтение),
  просмотр `build.prop`, конфигов, логов.
- **Раздел «Ядро»** — быстрые команды `uname -a`, cpuinfo, meminfo, dmesg,
  mounts, partitions, battery + просмотр `/proc/*` файлов.
- **«Открыть как Root»** у любого файла и **запуск .sh через Root** с двойным
  подтверждением и журналом аудита.
- Root проверяется только безопасной командой `su -c id`.

### 🧠 ИИ Мозг
- **Полноценные чаты** с историей и контекстом (40 последних реплик в запросе).
- Ваш собственный провайдер: URL + модель + API-ключ (шифруется Android
  Keystore, не покидает устройство без вашего ведома).
- Инструменты агента: `list`, `read`, `write`, `write_append` (неограниченные
  строки), `search`, `copy`, `move`, `rename`, `delete`, `configure`
  (настройки FZ Manager), `list_tools`, `create_tool` — **агент создаёт свои
  инструменты**.
- Иерархия безопасности: выключен по умолчанию → инструменты по одному →
  каждое опасное действие требует подтверждения → удаление только с
  отдельного opt-in → всё в аудит-журнале.

### ✨ Физзи — помощник, который знает всё
- Огромная локальная база знаний о FZ Manager: функции, шаги, FAQ, советы.
- **Контекст диалога**: «как это включить?», «подробнее» — продолжит тему.
- **Онлайн-режим** через вашего ИИ-провайдера с RAG (база знаний как контекст)
  и редактируемым системным промптом.
- **Кнопка скачивания мини-модели**: SmolLM2-135M (GGUF Q4_K_M, ~130 МБ) —
  самая лёгкая практичная модель для телефонов, почти не грузит систему.

### 🎨 Интерфейс
- Material 3, тёмная/светлая тема, 6 акцентных цветов, ползунок плотности.
- **Liquid Glass докбар** внизу: размытие, свечение, анимированный индикатор.
- Glass-карточки, hero-арт, аккуратные пустые состояния.
- Русский и английский, смена в любой момент.

### 🔔 Музыкальный островок
- Включите в настройках Физзи: при играющей музыке появляется живое
  медиа-уведомление «♪ FZ Manager» — на устройствах с островками (Dynamic
  Island / Mi Pill / Edge Lightning) выглядит как анимированный островок.
- Разрешение на уведомления запрашивается из приложения.

## Установка

1. Откройте [Releases](../../releases) и скачайте `FZ Manager vX.Y.Z.apk`
   (контрольная сумма — рядом `.sha256`).
2. Разрешите установку из «неизвестных источников».
3. При первом запуске пройдите онбординг и выдайте разрешения
   («Все файлы» открывается автоматически).
4. Root-функции требуют root (Magisk/Superuser). Без root остальное работает.

## Сборка из исходников

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

Для релизной подписи положите keystore и `key.properties` в `android/app/`
(см. SECURITY.md). CI GitHub Actions делает это из репозиторных secrets.

## Безопасность и приватность

- Никакой телеметрии, рекламы и скрытых сетевых запросов.
- API-ключ ИИ хранится зашифрованным в Android Keystore (AES-GCM).
- Root — только чтение системных файлов из UI; запись отсутствует намеренно.
- Каждое опасное действие (агентское или root) логируется в аудит-журнал.
- Подробности: [SECURITY.md](SECURITY.md).
