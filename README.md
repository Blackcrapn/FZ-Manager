# FZ Manager

Файловый менеджер нового поколения для Android (Flutter + Kotlin). / A next-generation Android file manager (Flutter + Kotlin).

## Возможности

- **Умный поиск путей** — живое автодополнение при вводе пути; несуществующие сегменты исправляются автоматически (например, `/data/lokal` → `/data/local`).
- **Файловый менеджер** — список/сетка, сортировка (имя/дата/размер), массовое выделение, избранное, закладки путей, недавние папки.
- **Root-раздел** — проверка root через безопасный `su -c id`, навигация по системным файлам (`ls` через su, только чтение).
- **ИИ Мозг** — реальный агент с циклом инструментов (list/read/write/write_append/search/move/delete + `create_tool` для создания собственных инструментов агентом). Кастомный провайдер (URL, модель, API-ключ). API-ключ шифруется Android Keystore. Опасные действия требуют подтверждения, удаление — только с отдельного разрешения.
- **Обучение** — онбординг (имя, фамилия, язык), запрос разрешений, интерактивный туториал с помощником Физзи и предупреждением при пропуске.
- **Физзи** — встроенный мини-помощник, который знает всё о FZ Manager (Root, ИИ Мозг, корзина, избранное, кастомизация, разрешения).
- **Корзина** — удаление в `.fz_trash` с восстановлением оттуда.
- **Обзор хранилища** — большие файлы (>50 МБ), недавние, закладки, сканеры-каркасы (анализ места, дубликаты).
- **Персистентность** — все настройки (тема, язык, акцент, плотность, избранное, закладки, недавние, разрешения ИИ) сохраняются между запусками.
- **Кастомизация** — тёмная/светлая тема, акцентный цвет, плотность интерфейса, язык RU/EN.

## Безопасность

- Root проверяется только командой `su -c id`; изменяющие команды требуют подтверждения и журналируются.
- ИИ-агент использует только явно разрешённые инструменты; каждое удаление подтверждается отдельно.
- API-ключ хранится зашифрованным (AES/GCM, Android Keystore), не попадает в исходный код и логи.
- См. [SECURITY.md](SECURITY.md).
